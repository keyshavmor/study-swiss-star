# Sequence-diagram reference corpus

Status: mixed `CURRENT — FRONTEND`, expected contract, and historical design.

These diagrams are retained because they provide detailed flow intent and
Lovable-visible paths. They do not prove that a local-backend endpoint exists.
Use the [API index](../cross-system/API_INDEX.md) and
[control matrix](../ui/CONTROL_TO_SYSTEM_MATRIX.md) to interpret each diagram's
implementation status. Maintained system-level sequences are under
[`../cross-system/diagrams`](../cross-system/diagrams/README.md).
