# Prompt 09 evidence index

The timestamped, immutable execution evidence is outside the application
worktree under `codex/evidence/prompt-09/`. The final run records:

- Git/source-authority state and changed-file scope;
- backend, frontend, type, lint, format, build and documentation commands;
- socket/process tests rerun in a normal host sandbox when required;
- endpoint/route counts and machine traceability validation;
- loopback/Lovable/secret scans;
- host, Python, Node, package-manager and tool versions;
- explicit physical-platform and production-service non-claims.

Canonical executable inventories:

- [`feature-traceability.json`](../../tests/contracts/feature-traceability.json)
- [`local-backend-v1.json`](../../tests/contracts/local-backend-v1.json)
- [`test_critical_journey_contracts.py`](../../tests/e2e/test_critical_journey_contracts.py)

No evidence file may contain secret values, real-user content or a claim that a
mock/simulation was a physical host test.
